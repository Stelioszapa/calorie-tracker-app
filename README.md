# NutriCal

A responsive Progressive Web App for tracking daily calories and macronutrients.

## Features

- Log meals and monitor calories, protein, carbohydrates, and fat
- Daily tracking, calendar view, and monthly statistics
- Multiple user profiles and editable nutrition goals
- Data stored locally on the device
- PWA-ready for installation on mobile devices

## Tech stack

React, Vite, Tailwind CSS, and Recharts.

## Run locally

```bash
npm install
npm run dev
```

## 🚀 Εναλλακτικές δωρεάν επιλογές δημοσίευσης

Για να έχετε πρόσβαση και οι δύο στα κινητά σας 24/7 χωρίς να είναι ανοιχτό το Mac:

### Τρόπος 1: Netlify Drop (Ο πιο εύκολος τρόπος - 1 λεπτό)
1. Ανοίξτε στον browser τη σελίδα: **[app.netlify.com/drop](https://app.netlify.com/drop)**
2. Σύρετε (Drag & Drop) ολόκληρο τον φάκελο:
   ` /Users/stelioszapa/.gemini/antigravity/scratch/calorie-tracker-app `
3. Μέσα σε λίγα δευτερόλεπτα το Netlify θα σας δώσει ένα δωρεάν Link (π.χ. `https://nutrical-app.netlify.app`).

### Τρόπος 2: Vercel (Συνιστάται)
1. Συνδεθείτε στο **[Vercel.com](https://vercel.com)**.
2. Πατήστε **Import Project** συνδέοντας το repository σας ή ανεβάζοντας το φάκελο.
3. Το Vercel θα δημιουργήσει δωρεάν μόνιμο σύνδεσμο HTTPS.

## 📲 Πώς να την εγκαταστήσετε στα κινητά σας (PWA App)

Ανοίξτε το link της εφαρμογής από το κινητό:

- **Σε iPhone (Safari)**: Πατήστε το κουμπί **Κοινοποίηση** (τετράγωνο με βέλος) -> **"Προσθήκη στην οθόνη αφετηρίας"** (Add to Home Screen).
- **Σε Android (Chrome)**: Πατήστε τις **3 τελείες** επάνω δεξιά -> **"Προσθήκη στην αρχική οθόνη"** (Add to Home screen) ή **"Εγκατάσταση εφαρμογής"**.
